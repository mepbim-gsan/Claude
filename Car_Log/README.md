# CarLog

自動車にかかる費用・走行を記録する単一HTMLツール（スマホ最適化・下部タブ）。

## 機能
- **複数台管理**: ヘッダーの車両名をタップで切替・追加。初期状態で「サンプル」車を同梱（設定から作り直し可）
- **ホーム**: 年/全期間の費用合計・走行距離・平均燃費・維持費/km、次回予定・期限、月別（年別）費用グラフ、費用内訳
- **給油ログ**: 日付・ODO・給油量・単価・金額（自動計算/単価逆算）・満タン/部分・油種・スタンド。満タン法で燃費算出、燃費推移グラフ
- **ODOログ**: ODO手入力＋給油・メンテのODOを統合表示。月別/年別走行距離（記録間を線形補間）
- **メンテナンス**: 車検・点検・オイル交換・洗車・手洗い洗車・コーティング・カスタム等。次回予定日/ODOをホームに表示
- **その他費用**: 車両購入・保険・税金・駐車場など。初期費用フラグ（維持費から除外）、期限（満期日）をホームに表示
- **設定**: 車両一覧・車両情報、購入時の費用（初期費用）、テーマ、区分の編集、JSONバックアップ/復元、サンプル車の作り直し

## データ・同期
- 端末内（localStorage `carlog-data-v1`）に保存。未ログインでも使える
- 設定「クラウド同期」で Firebase config を設定し Googleログインすると、Firestore（`users/{uid}/data/carlog-main`）でスマホ・PC間を同期
  - サンプル車・表示中の車両は同期しない（端末ごと）
  - 未ログイン中に編集したデータがクラウドと異なる場合、ログイン時にどちらを使うか選択
  - ログアウトしても端末内のデータは残る
- PWA 対応（ホーム画面に追加・オフライン起動）
