# bat_monitor

複数モニター接続時に、表示モード・解像度・DPIスケールをまとめて設定する Windows バッチスクリプト。

## 背景

新しい PC を複数モニターに初めて接続すると、表示モードが「複製」のままになりがち。  
自宅と会社でモニターのサイズや倍率が異なるため、設定を場所ごとに簡単に切り替えられるようにした。

## 使い方

### 1. ファイルをコピーして場所ごとに用意する

```
bat_monitor.bat  ← テンプレート（そのままでも動作可）
home.bat         ← bat_monitor.bat をコピーして自宅用に設定
office.bat       ← bat_monitor.bat をコピーして会社用に設定
```

### 2. 設定欄を書き換える

ファイルを開き、先頭の **設定欄** の値を環境に合わせて変更する。

```batch
:: --- モニター 1（プライマリ） ---
set MON1_WIDTH=1920    ← 横ピクセル数
set MON1_HEIGHT=1080   ← 縦ピクセル数
set MON1_REFRESH=60    ← リフレッシュレート（Hz）
set MON1_SCALE=96      ← DPI スケール値（下表参照）

:: --- モニター 2（セカンダリ） ---
set MON2_WIDTH=2560
set MON2_HEIGHT=1440
set MON2_REFRESH=60
set MON2_SCALE=120

:: 接続モニター数（1 or 2）
set MONITOR_COUNT=2
```

#### DPI スケール値の対応表

| Windows 表示倍率 | SCALE 値 |
|:---:|:---:|
| 100% | 96 |
| 125% | 120 |
| 150% | 144 |
| 175% | 168 |
| 200% | 192 |

### 3. 実行する

外部モニターを接続した状態でバッチファイルをダブルクリックして実行する。  
管理者権限は不要。

## スクリプトが行うこと

1. 接続中モニター数を確認（1 台のみ検出された場合は警告して終了）
2. `DisplaySwitch.exe /extend` で**拡張モード**に切り替え
3. 各モニターの**解像度・リフレッシュレート**を設定
4. 各モニターの **DPI スケール**をレジストリに書き込み

> **注意**: DPI スケールの変更は、サインアウト後の再サインインで完全に反映されます。

## 動作環境

- Windows 10 / 11
- PowerShell 5.1 以上（OS 標準搭載）
- 追加ツール不要
