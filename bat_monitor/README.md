# bat_monitor

複数モニター接続時に、表示モード・解像度・配置・DPIスケールをまとめて設定する Windows バッチスクリプト。

## 背景と解決する問題

- 新しい PC を複数モニターに初めて接続すると、表示モードが「複製」のままになりがち
- 自宅と会社でモニターのサイズや倍率が異なるため、場所ごとの設定ファイルを簡単に切り替えたい
- ノートPCは開いた状態（内蔵＋外部）と閉じた状態（外部のみ）でモニター番号が変わる問題がある

## ファイル構成

```
bat_monitor/
├── bat_monitor.bat       ← 設定テンプレート（コピーして使う）
├── _monitor_helper.ps1   ← 実装（直接実行しない）
└── README.md
```

## 使い方

### 1. ファイルをコピーして場所ごとに用意する

```
bat_monitor.bat  ← テンプレート
home.bat         ← bat_monitor.bat をコピーして自宅用設定に書き換え
office.bat       ← bat_monitor.bat をコピーして会社用設定に書き換え
```

`_monitor_helper.ps1` は bat と同じフォルダに置いておく。

### 2. 設定欄を書き換える

各 bat ファイル先頭の **設定欄** を環境に合わせて変更する。

```batch
set SKIP_INTERNAL=YES   ← ノートPC内蔵画面を除外（YES/NO）
set PRIMARY_MON=1       ← メインにする外部モニター番号（1 or 2）
set LAYOUT=1-2          ← 並び順（下表参照）

:: --- 外部モニター 1 ---
set MON1_WIDTH=1920
set MON1_HEIGHT=1080
set MON1_REFRESH=60
set MON1_SCALE=96       ← DPI スケール値（下表参照）

:: --- 外部モニター 2 ---
set MON2_WIDTH=2560
set MON2_HEIGHT=1440
set MON2_REFRESH=60
set MON2_SCALE=120

set MONITOR_COUNT=2     ← 使用する外部モニター数
```

#### LAYOUT

| 値 | 配置 | 条件 |
|:---:|:---|:---|
| `1-2` | MON1 左 / MON2 右 | - |
| `2-1` | MON2 左 / MON1 右 | - |
| `1-L-2` | MON1 左 / 内蔵ディスプレイ中央 / MON2 右 | 蓋が開いている時のみ |
| `2-L-1` | MON2 左 / 内蔵ディスプレイ中央 / MON1 右 | 蓋が開いている時のみ |

蓋が閉じている場合、`1-L-2` は `1-2` に、`2-L-1` は `2-1` に自動でフォールバックします。

#### DPI スケール値

| Windows 表示倍率 | SCALE 値 |
|:---:|:---:|
| 100% | 96 |
| 125% | 120 |
| 150% | 144 |
| 175% | 168 |
| 200% | 192 |

### 3. 外部モニターを接続した状態でバッチをダブルクリック

管理者権限は不要。

## スクリプトが行うこと

1. アクティブなモニター数を確認（1台のみなら警告して終了）
2. `DisplaySwitch.exe /extend` で**拡張モード**に切り替え
3. `QueryDisplayConfig` API で内蔵ディスプレイを自動識別し除外（`SKIP_INTERNAL=YES` 時）
4. 各外部モニターに**解像度・リフレッシュレート・位置**を設定
5. 指定したモニターを**メイン（プライマリ）**に設定
6. レジストリに**DPI スケール**を書き込み、`WM_SETTINGCHANGE` で即時反映を試みる

## モニター番号の考え方

`SKIP_INTERNAL=YES` の場合、内蔵ノート画面はスキップされるため:

| ノートPCの状態 | MON1 | MON2 |
|:---:|:---:|:---:|
| 画面を開いている | 外部モニター1台目 | 外部モニター2台目 |
| 画面を閉じている | 外部モニター1台目 | 外部モニター2台目 |

ノートの開閉に関わらず、常に「外部モニターの接続順」で番号が振られる。

## 注意事項

- **DPI スケール**は即時反映を試みます。一部のアプリは再ログインまで更新されない場合があります
- **解像度・配置・メイン設定**はスクリプト実行直後に反映される
- DPI 設定は初回起動時（レジストリキー未作成）は効かない場合がある。  
  その場合は一度手動でスケールを設定した後、スクリプトで上書きする

## 動作環境

- Windows 10 / 11
- PowerShell 5.1 以上（OS 標準搭載）
- 追加ツール不要
