# いつやった？

家の定期メンテナンス（フィルター交換・掃除・ごみ捨て・大掃除など）の「最後にいつやったか」を記録する単一HTMLツール（スマホ最適化・下部タブ）。

## 機能
- **一覧**: 項目ごとに最終実施日と経過日数を表示。✓ ボタンで今日の実施を記録（取り消し可）
  - 目安の間隔（任意）を設定した項目は、次回までのカウントダウンと期限切れを表示
  - 並び順: 期限順 / 放置順（最後の実施が古い順）
  - タグで絞り込み。「年度管理」タグでは今年度の実施済み／未実施と進捗を表示
- **内訳**: 1つの項目に複数の内訳（例: トイレ 1F/2F、給気口 部屋ごと、キッチン コンロ/換気扇/流し台）を持ち、内訳ごとに記録
- **項目詳細**: タグ・目安・型番・購入先リンク・備考、内訳ごとの最終実施、メモ（日付・記録者付き、編集・削除可）、実施履歴（編集・削除可）
- **履歴**: 実施記録とメモを日付順に表示
- **設定**: 記録者（この端末の記録者）、タグ（年度管理 ON/OFF）、年度の開始月、テーマ、JSONバックアップ/復元
- **サンプルモード**: サンプルデータを一時的に表示（変更は保存されず、自分のデータはそのまま）

## データ
- 端末内（localStorage `itsuyatta-data-v1`）に保存。この端末の記録者は `itsuyatta-me`
- Firebase による家族共有は今後対応予定
