# 太陽光ダッシュボード

## 概要

太陽光ダッシュボードは、太陽光発電システムのデータを分析・可視化するためのWebアプリケーションです。CSVファイルから発電データを読み込み、Firebaseを活用したクラウド同期機能により、複数のデバイス間でデータを共有できます。

### 主な機能

- **データ入力**: CSVファイル（30分または1時間粒度）からデータをインポート
- **クラウド同期**: Google認証によるFirebase Firestoreとの同期
- **ゲストモード**: ログイン不要でローカルデータのみを使用
- **ダッシュボード**: 日次/月次/年次/推移/分析の5つのタブでデータを分析
  - 日次: 日別サマリー表、時間帯別平均、ヒートマップ
  - 月次: 日別棒グラフ、月別サマリー表、自家消費分析
  - 年次: 月別棒グラフ、年別サマリー表、自家消費分析
  - 推移: 年別集計、累計グラフ、経年劣化診断
  - 分析: 季節別平均、ヒストグラム、ランキング
- **ライト/ダークモード**: ユーザーの好みに応じた表示切り替え
- **レスポンシブデザイン**: PCおよびスマートフォン対応

### 技術仕様

- HTML5, CSS3, JavaScript (ES6+)
- Chart.js for データ可視化
- Firebase for クラウド同期
- PWA対応 (オフライン使用可能)

### 使用方法

1. index.htmlをブラウザで開く
2. CSVファイルをアップロードまたはFirebaseで同期
3. 各タブでデータを分析
