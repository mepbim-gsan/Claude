# タイムカード

勤怠管理・JOB実績記録のためのシングルページWebアプリ。スマートフォン最適化済みのPWA対応ツール。

---

## 機能一覧

### 打刻タブ
- 出勤・退勤・休憩開始・休憩終了をボタン1タップで記録
- 現在時刻のリアルタイム表示（ライブバッジ）
- 前日・翌日への日付切り替え
- 退勤済み時は休憩ボタンを自動無効化
- 法定超過見込み時間のフォールバック計算（退勤未入力時対応）

### 月次タブ
- 月ごとの日次一覧（出退勤時刻・休憩時間・労働時間）
- 月次サマリー：所定・実績・法定超過・所定超過などの集計ボックス
- 折れ線グラフによる月次推移表示（Chart.js）
- 勤務時間帯ヒートマップ（15分粒度・日付列スクロール固定・移動平均線付き）
- 休暇タイプ別の色分け表示（全休・半休・時間休・特別休暇等）
- 日次モーダルから実績の追加・編集・削除
- 休憩時間の複数区間入力（勤務時間外休憩のバリデーション付き）
- 予定（シフト）の一括入力カード（折りたたみ対応）
- 月ナビゲーションで過去・未来月への切り替え

### JOB実績タブ
- 月間カレンダー × 96列（15分単位）のグリッドでWORK実績を塗りつぶし記録
- 2点タップ範囲塗り方式（スマホスクロール誤塗り防止・長押し連続塗り/消し対応）
- 選択中WORKの切り替えボタン（プリセット絞り込みフィルター付き・横スクロール）
- WORK別・JOBNO別の集計サマリー（クリックでWORK内訳モーダルを表示）
- カテゴリ別比率の表示
- ロックセル表示（休日・休憩時間帯を別色でロック）
- ツールチップ（ホバー・長押しで日時・WORK名・メモを表示）

#### WORK管理
- WORK（作業項目）の追加・編集・アーカイブ・削除
- WORKにJOBNO・メモフィールドを設定可能
- カラーパレットによるWORK単位の色設定
- 命名規則から自動生成するプリセット絞り込みボタン
- スワイプ操作でアーカイブ・削除（PC表示では常時ボタン表示）
- PC表示時は2カラムレイアウト

### 年間タブ
- 月別の勤怠サマリーテーブル（所定・実績・超過・休暇日数）
- 月別積み上げ棒グラフ（正規・超過・休暇の内訳）
- 年間円グラフ（構成比率）

### 設定タブ
- ダーク / ライトテーマ切り替え
- 所定労働時間・みなし時間などのパラメータ設定
- 祝日データの管理
- プリセットシフトの登録
- Firebase設定のUI（configを貼り付けて保存・再設定）
- Excelエクスポート（xlsx.js）

## 認証・データ同期

| モード | 説明 |
|--------|------|
| **Googleログイン** | Firebase AuthによるGoogleアカウント認証。Firestoreにユーザー別保存・リアルタイム同期 |
| **ログインなし** | localStorageにデータ保存。クラウド同期なし |

- 初回ログイン時：localStorageのキャッシュを自動アップロード
- 再ログイン時：未ログイン中の編集とクラウドデータが競合する場合は確認ダイアログを表示
- ログアウト時：localStorageをクリアしてログイン画面に戻る

## 技術スタック

| ライブラリ | 用途 |
|-----------|------|
| Firebase 10.x | Authentication（Googleログイン）・Firestore（クラウド保存） |
| Chart.js 4.4 | 月次グラフ・ヒートマップ・年間グラフ |
| SheetJS (xlsx) 0.18 | Excelエクスポート |

- **PWA対応**：`manifest.json` + Appleメタタグ、ホーム画面追加に対応
- **シングルファイル構成**：`index.html` 1ファイルで完結
- **レスポンシブ**：スマートフォン優先設計、PC（768px以上）では一部レイアウトを2カラム化
