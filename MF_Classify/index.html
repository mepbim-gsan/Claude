🔥 Firebase設定

🔄 データ管理

Googleログイン後にFirebaseと同期できます。

🔐 Firestoreセキュリティルール

Firebase Console → Firestore → ルール で以下を設定してください：

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /categories/{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
